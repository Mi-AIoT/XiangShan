## 1. 什么是 SimPoint？

### 1.1 简单定义

SimPoint (Simulation Points) 是一种**统计采样技术**，用于从程序的数十亿条指令中找到最具代表性的"采样点"，只需仿真这些采样点就能准确估算全程序的性能。

### 1.2 类比理解

**嵌入式工程师的类比**：

想象你要测量一个复杂嵌入式系统的功耗：
- **传统方法**：运行完整程序，记录整个过程的功耗 → 耗时数天
- **SimPoint 方法**：找到程序的几个"代表性阶段"，只测量这几个阶段 → 耗时数小时

就像医生不需要 24 小时监测你的心跳，只需要在几个关键时刻测量就能判断健康状况。

## 2. 为什么需要 SimPoint？

### 2.1 仿真速度问题

| 仿真方式 | 速度 | 运行 SPEC2006 所需时间 |
|----------|------|------------------------|
| 真实硬件 | 3 GHz | 几小时 |
| RTL 仿真 (VCS) | 1-10 Hz | 数月 |
| RTL 仿真 (Verilator) | 10-100 Hz | 数周 |
| ISA 模拟器 (NEMU) | 100 MHz | 数天 |

**关键问题**：RTL 仿真太慢，完整运行 SPEC2006 不现实。

### 2.2 SimPoint 的效果

```
完整程序：100 亿条指令 → 仿真 100 小时
SimPoint：10 个采样点 × 1000 万条指令 → 仿真 10 小时
                                    ↓
                            精度 97%+
```

## 3. 核心思想：程序阶段理论

### 3.1 程序阶段 (Phase) 概念

**理论基础**：程序的执行可以分成若干"阶段"，每个阶段内的行为高度相似。

```
程序执行时间线：
[阶段A][阶段B][阶段A][阶段C][阶段B][阶段A][阶段C]
  ↓       ↓       ↓       ↓       ↓       ↓       ↓
相似    相似    相似    相似    相似    相似    相似
```

**类比**：
- 嵌入式系统中的"初始化阶段"、"运行阶段"、"休眠阶段"
- 每个阶段的行为模式不同，但同一阶段内行为相似

### 3.2 阶段的特征

| 特征 | 说明 |
|------|------|
| **IPC 稳定** | 同一阶段内，每周期指令数相对稳定 |
| **缓存行为相似** | 缓存命中率、访问模式相似 |
| **分支模式相似** | 分支预测成功率相似 |
| **内存访问相似** | 内存访问模式、TLB 命中率相似 |

### 3.3 阶段边界

阶段之间的边界通常由以下事件触发：
- 函数调用/返回
- 循环结构变化
- 数据访问模式变化
- 程序输入变化

## 4. 基本块向量 (BBV)

### 4.1 什么是基本块？

**基本块 (Basic Block)**：一段没有分支的连续指令序列。

```assembly
# 基本块示例
add x1, x2, x3    # ─┐
sub x4, x1, x5    #  │ 基本块：没有分支，顺序执行
mul x6, x4, x7    # ─┘
beq x6, x0, label  # ← 分支：基本块结束
```

### 4.2 BBV 的定义

**基本块向量 (Basic Block Vector)**：一个向量，记录程序执行过程中每个基本块被执行的次数。

```
假设程序有 1000 个基本块：
BBV = [次数_1, 次数_2, 次数_3, ..., 次数_1000]
```

**示例**：

```
程序有 5 个基本块：BB1, BB2, BB3, BB4, BB5

执行 100 万条指令后：
BBV = [100000, 200000, 150000, 300000, 250000]
       ↑BB1    ↑BB2     ↑BB3    ↑BB4    ↑BB5

归一化后（除以总指令数）：
BBV_norm = [0.1, 0.2, 0.15, 0.3, 0.25]
```

### 4.3 为什么用 BBV？

**BBV 的优势**：

| 优势 | 说明 |
|------|------|
| **捕获程序行为** | BBV 反映了程序的执行模式 |
| **降维** | 将数十亿指令压缩为一个向量 |
| **可比较** | 可以计算两个 BBV 之间的"距离" |
| **阶段识别** | 相似 BBV 表示相似阶段 |

**类比**：
- 就像用"频谱"来描述音频信号
- BBV 就是程序执行的"频谱"

### 4.4 BBV 提取过程

```
程序执行
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│                    BBV 提取过程                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 定义基本块边界                                       │
│     - 编译器标记每个基本块的 ID                          │
│     - 每个基本块有唯一编号 (0, 1, 2, ...)               │
│                                                         │
│  2. 执行时计数                                           │
│     - 每执行一个基本块，对应计数器 +1                    │
│     - 使用"间隔"统计（如每 1000 万条指令）              │
│                                                         │
│  3. 生成 BBV                                             │
│     - 每个间隔生成一个 BBV                              │
│     - BBV[i] = 基本块 i 在该间隔内的执行次数            │
│                                                         │
│  4. 归一化                                               │
│     - BBV_norm = BBV / sum(BBV)                         │
│     - 使得不同间隔的 BBV 可比较                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.5 BBV 示例

**假设**：一个简单的循环程序

```c
for (int i = 0; i < 1000000; i++) {
    if (i % 2 == 0) {
        // 基本块 A：偶数处理
        process_even(i);
    } else {
        // 基本块 B：奇数处理
        process_odd(i);
    }
    // 基本块 C：公共部分
    common_work(i);
}
```

**BBV 提取**：

```
间隔 1 (0-100万指令)：
BBV = [500000, 500000, 1000000, ...]  # A=50万, B=50万, C=100万

间隔 2 (100万-200万指令)：
BBV = [500000, 500000, 1000000, ...]  # 相同模式

间隔 3 (200万-300万指令)：
BBV = [500000, 500000, 1000000, ...]  # 相同模式
```

**观察**：所有间隔的 BBV 都很相似，说明这个程序只有一个"阶段"。

## 5. K-Means 聚类分析

### 5.1 什么是聚类？

**聚类 (Clustering)**：将相似的对象分到同一组。

**类比**：
- 将嵌入式任务按"CPU 占用率"分组
- 高占用任务一组，低占用任务一组

### 5.2 K-Means 算法

**K-Means** 是最常用的聚类算法：

```
输入：N 个 BBV 向量，K 个聚类（如 K=10）
输出：每个 BBV 属于哪个聚类

步骤：
1. 随机选择 K 个初始聚类中心
2. 将每个 BBV 分配到最近的聚类中心
3. 重新计算每个聚类的中心（该聚类所有 BBV 的平均值）
4. 重复步骤 2-3，直到收敛
```

### 5.3 K-Means 在 SimPoint 中的应用

```
输入：程序的所有 BBV（如 1000 个间隔）
      K = 10（希望找到 10 个代表性阶段）

过程：
┌─────────────────────────────────────────────────────────┐
│                    K-Means 聚类                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  BBV1  ─┐                                               │
│  BBV2  ─┼─▶ 聚类 1 (阶段 A)                            │
│  BBV3  ─┘                                               │
│                                                         │
│  BBV4  ─┐                                               │
│  BBV5  ─┼─▶ 聚类 2 (阶段 B)                            │
│  BBV6  ─┘                                               │
│                                                         │
│  BBV7  ─┐                                               │
│  BBV8  ─┼─▶ 聚类 3 (阶段 C)                            │
│  BBV9  ─┘                                               │
│                                                         │
│  ...                                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘

输出：10 个聚类，每个聚类代表一个程序阶段
```

### 5.4 聚类数量 K 的选择

**问题**：如何确定 K 的值？

**方法 1：肘部法则 (Elbow Method)**

```
计算不同 K 值的"误差平方和"(SSE)：
K=1:  SSE=1000
K=5:  SSE=500
K=10: SSE=200
K=15: SSE=180  ← 下降变缓
K=20: SSE=175

选择"肘部"：K=10-15
```

**方法 2：实际经验**

| 程序类型 | 推荐 K 值 | 说明 |
|----------|-----------|------|
| 简单程序 | 5-10 | 阶段少 |
| 复杂程序 | 10-20 | 阶段多 |
| SPEC2006 | 10-20 | 标准选择 |

### 5.5 距离度量

**如何计算两个 BBV 之间的"距离"？**

**欧氏距离**：
```
distance(BBV1, BBV2) = sqrt(Σ(BBV1[i] - BBV2[i])²)
```

**余弦相似度**（更常用）：
```
similarity(BBV1, BBV2) = (BBV1 · BBV2) / (|BBV1| × |BBV2|)
```

**类比**：
- 欧氏距离：两个向量的"绝对距离"
- 余弦相似度：两个向量的"方向相似性"

## 6. 采样点选择算法

### 6.1 什么是采样点？

**采样点 (Simulation Point)**：聚类中最具代表性的 BBV，用于代表整个聚类。

```
聚类 1 (阶段 A)：
BBV1, BBV2, BBV3, BBV4, BBV5

选择采样点：
选择 BBV3 作为采样点（最接近聚类中心）
```

### 6.2 选择算法

**方法 1：最近中心点**

```
对于每个聚类：
  1. 计算聚类中心（所有 BBV 的平均值）
  2. 找到距离中心最近的 BBV
  3. 该 BBV 对应的间隔就是采样点
```

**方法 2：代表性点**

```
对于每个聚类：
  1. 计算每个 BBV 到其他所有 BBV 的平均距离
  2. 选择平均距离最小的 BBV
  3. 该 BBV 对应的间隔就是采样点
```

### 6.3 采样点数量

**问题**：需要多少个采样点？

**理论分析**：
- 采样点越多，精度越高
- 但仿真时间也越长

**实践选择**：

| 采样点数量 | 精度 | 仿真时间 | 适用场景 |
|------------|------|----------|----------|
| 5-10 | 90-95% | 短 | 快速评估 |
| 10-20 | 95-98% | 中 | 标准评估 |
| 20-50 | 98-99% | 长 | 高精度评估 |

**XiangShan 的选择**：10-20 个采样点

## 7. 权重计算方法

### 7.1 权重的定义

**权重 (Weight)**：采样点代表的阶段在全程序中的占比。

```
权重 = 该阶段的指令数 / 总指令数
```

### 7.2 权重计算过程

**步骤 1：统计每个聚类的指令数**

```
聚类 1 (阶段 A)：包含间隔 1, 2, 3, 4, 5
  - 间隔 1：1000 万条指令
  - 间隔 2：1000 万条指令
  - 间隔 3：1000 万条指令
  - 间隔 4：1000 万条指令
  - 间隔 5：1000 万条指令
  - 总计：5000 万条指令

聚类 2 (阶段 B)：包含间隔 6, 7, 8, 9, 10
  - 总计：5000 万条指令

...
```

**步骤 2：计算权重**

```
总指令数 = 1 亿条

聚类 1 的权重 = 5000 万 / 1 亿 = 0.5
聚类 2 的权重 = 5000 万 / 1 亿 = 0.5
```

**步骤 3：归一化**

```
归一化权重 = 权重 / 所有权重之和

如果所有权重之和 = 1.0，则不需要归一化
如果所有权重之和 ≠ 1.0，则需要归一化
```

### 7.3 权重的物理意义

**权重表示**：该阶段在全程序执行中的"重要性"。

```
示例：
聚类 1 权重 = 0.25  → 该阶段占全程序的 25%
聚类 2 权重 = 0.75  → 该阶段占全程序的 75%
```

**加权平均**：

```
全程序 IPC = 权重1 × IPC1 + 权重2 × IPC2 + ...
           = 0.25 × 2.0 + 0.75 × 4.0
           = 0.5 + 3.0
           = 3.5
```

```
采样点 11: 6.57%

总和 ≈ 100%
```

## 8. SimPoint 工具使用

### 8.1 SimPoint 工具概述

**SimPoint 工具**：由加州大学圣地亚哥分校 (UCSD) 开发的开源工具。

**GitHub 仓库**：https://github.com/SimulatorWorks/SimPoint

### 8.2 工具组成

```
SimPoint 工具包：
├── simpoint        # 主程序：执行聚类和采样点选择
├── bvcompress      # BBV 压缩工具
├── utilities/      # 辅助工具
└── docs/           # 文档
```

### 8.3 使用流程

**步骤 1：提取 BBV**

```bash
# 使用 ISA 模拟器（如 NEMU）提取 BBV
# 每 1000 万条指令生成一个 BBV
./nemu --bbv --bbv-interval 10000000 program.elf

# 输出：bbv_file.gz
```

**步骤 2：运行 SimPoint**

```bash
# 运行 SimPoint 聚类
./simpoint \
    -inputVectors bbv_file.gz \
    -maxK 20 \                    # 最多 20 个聚类
    -numInitSeeds 10 \            # 10 个随机种子
    -saveSimPoints simpoints.txt \ # 保存采样点
    -saveWeights weights.txt       # 保存权重
```

**步骤 3：输出文件**

```
simpoints.txt:
3          # 采样点 1：间隔 3
15         # 采样点 2：间隔 15
27         # 采样点 3：间隔 27
...

weights.txt:
0.244818   # 采样点 1 的权重
0.168269   # 采样点 2 的权重
0.081793   # 采样点 3 的权重
...
```

### 8.4 SimPoint 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-maxK` | 最大聚类数 | 20 |
| `-numInitSeeds` | 随机种子数 | 10 |
| `-inputVectors` | BBV 文件路径 | 无 |
| `-saveSimPoints` | 采样点输出路径 | 无 |
| `-saveWeights` | 权重输出路径 | 无 |

### 9.3 XiangShan 的加权计算

**代码位置**：`scripts/top-down/top_down.py:62-95`

```python
def proc_input(wl_df: pd.DataFrame, js: dict, workload: str):
    """
    单个 workload 的加权计算
    
    参数:
        wl_df: 该 workload 所有采样点的性能数据
        js: JSON 配置（采样点权重）
        workload: workload 名称
    """
    # 按采样点排序
    wl_df = wl_df.sort_values(by=['point'])
    
    # 获取权重
    wl_js = dict(js[workload])
    vec_weight = pd.DataFrame.from_dict(wl_js['points'], orient='index')
    vec_weight.index = vec_weight.index.astype(np.int64)
    
    # 只保留实际运行的采样点
    vec_weight = vec_weight.loc[wl_df['point']]
    vec_weight.columns = ['weight']
    
    # 归一化权重
    coverage = np.sum(vec_weight.values)
    vec_weight = vec_weight / coverage
    
    # 矩阵乘法计算加权平均
    weight_metrics = np.matmul(
        vec_weight.values.reshape(1, -1),  # 权重向量 (1, W)
        wl_df.values                        # 性能矩阵 (W, N)
    )
    
    return weight_metrics, wl_df.columns, coverage
```

## 10. 与嵌入式采样的对比

### 10.1 SimPoint vs 嵌入式功耗采样

| 方面 | SimPoint | 嵌入式功耗采样 |
|------|----------|----------------|
| **采样对象** | 程序执行行为 | 电流/电压 |
| **采样方法** | BBV + 聚类 | 等间隔 ADC 采样 |
| **采样点选择** | 统计学习 | 固定间隔 |
| **权重计算** | 聚类占比 | 平均值 |
| **精度** | 97%+ | 取决于采样率 |

### 10.2 SimPoint vs 示波器采样

| 方面 | SimPoint | 示波器采样 |
|------|----------|------------|
| **采样原理** | 行为聚类 | 时间采样 |
| **采样点** | 代表性阶段 | 等间隔点 |
| **数据压缩** | 高（10-20 个点） | 低（所有点） |
| **适用场景** | 长时间运行 | 瞬态信号 |

### 10.3 SimPoint 的优势

**对于嵌入式工程师**：

1. **节省时间**：从数周缩短到数小时
2. **保持精度**：97%+ 的精度足够做性能评估
3. **可重复**：相同的采样点，结果可重复
4. **可比较**：不同 CPU 设计可以用相同采样点比较

### 10.4 SimPoint 的局限

**需要注意**：

1. **不是精确测量**：是统计估算，有误差
2. **依赖程序行为**：如果程序行为变化大，精度下降
3. **需要预处理**：需要先提取 BBV，运行 SimPoint
4. **采样点固定**：换程序需要重新生成采样点

## 总结

### SimPoint 采样点产生流程

```
1. 程序执行 → 提取 BBV（基本块向量）
2. BBV 聚类 → 使用 K-Means 算法
3. 选择采样点 → 每个聚类选一个代表性点
4. 计算权重 → 该阶段占全程序的比例
5. 输出配置 → JSON 格式
```

### 关键概念

| 概念 | 说明 |
|------|------|
| **BBV** | 基本块向量，描述程序执行模式 |
| **K-Means** | 聚类算法，将相似 BBV 分组 |
| **采样点** | 聚类中最具代表性的 BBV |
| **权重** | 该阶段在全程序中的占比 |

### 对嵌入式工程师的建议

1. **理解 BBV**：BBV 是程序行为的"指纹"
2. **理解聚类**：聚类是将相似行为分组
3. **理解权重**：权重表示重要性
4. **实践使用**：尝试用 SimPoint 工具分析一个简单程序
